# Ефимовна v6.0

Программа для подготовки макетов и работы с плоттерами.

## Важные ограничения

Программа не считывает все физические состояния плоттера. Во время работы оператору необходимо наблюдать за устройством.

Для USB Serial используйте поддерживаемый браузер (Chrome) и HTTPS-версию программы.

## Скачать

Файл программы: [Ефимовна_v6.0.html](./Ефимовна_v6.0.html)

## Сообщить об ошибке

Укажите модель плоттера, способ подключения, браузер и операционную систему. Не прикладывайте файлы заказов и данные клиентов без разрешения.

Физически проверено:
- YGTECH SK 870T — USB Serial;
- Speilo KI-720S — прямой USB.

Совместимость с другими моделями не подтверждена. Программа не считывает все физические состояния плоттера; перед работой проверьте макет и настройки и наблюдайте за устройством.
