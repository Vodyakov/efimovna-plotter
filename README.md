# Ефимовна v6.0

Программа для подготовки макетов и работы с плоттерами.

## Проверено на оборудовании

- YGTECH SK 870T — USB Serial
- Speilo KI-720S — прямой USB; проверена на реальном заказе

Другие модели пока не подтверждены.

## Важные ограничения

Программа не считывает все физические состояния плоттера. Во время работы оператору необходимо наблюдать за устройством.

Для USB Serial используйте поддерживаемый браузер и HTTPS-версию программы.
